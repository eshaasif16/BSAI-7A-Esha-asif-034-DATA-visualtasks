# Part F data source

- **Dataset:** unemployment-across-industries.json - unemployed persons (thousands) and unemployment rate
  by industry, monthly, January 2000 to February 2010, 14 industries (category column: `series`).
  Not seasonally adjusted.
- **Where it came from:** the `vega-datasets` repository
  (https://github.com/vega/vega-datasets, file `data/unemployment-across-industries.json`),
  which describes the data as US Bureau of Labor Statistics unemployment figures.
- **Downloaded:** 18 October 2026, from
  https://raw.githubusercontent.com/vega/vega-datasets/main/data/unemployment-across-industries.json
- **Original publisher:** US Bureau of Labor Statistics. The file in this folder is the unmodified download.
